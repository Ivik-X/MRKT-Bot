# 🔑 MRKT Token Grabber (Chrome Extension)

Расширение для Google Chrome (и браузеров на базе Chromium: Brave, Edge, Яндекс.Браузер), предназначенное для автоматического сбора токенов авторизации маркетплейса **MRKT (`tgmrkt.io`)**.

---

## 🚀 Установка за 30 секунд

1. Откройте Google Chrome и перейдите по адресу:
   ```text
   chrome://extensions/
   ```
2. В правом верхнем углу включите переключатель **«Режим разработчика»** (*Developer mode*).
3. В левом верхнем углу нажмите кнопку **«Загрузить распакованное расширение»** (*Load unpacked*).
4. Выберите папку:
   ```text
   /Users/polzovatel/projects/mrkt-bot/chrome_token_grabber
   ```
5. Расширение появится в списке. Нажмите на значок «пазла» в панели Chrome и **закрепите значок 🔑 булавкой**.

---

## 🎯 Инструкция по использованию

1. Нажмите на иконку расширения в панели браузера.
2. Нажмите большую зелёную кнопку **«⏺ Начать запись»**.
   - Значок расширения загорится зелёным цветом с индикатором `REC`.
3. Заходите в свои Telegram-аккаунты (через [Telegram Web](https://web.telegram.org) или напрямую в WebApp MRKT `tgmrkt.io`):
   - Как только страница MRKT отправляет любой сетевой запрос, расширение перехватывает токен из заголовка `Authorization` или cookie `access_token`.
   - Всплывёт системное уведомление Chrome: `🎯 Токен MRKT перехвачен! Аккаунт #N: abc12345...`.
   - На значке расширения счётчик увеличится на 1.
4. Повторите вход для каждого вашего аккаунта (например, переключая профили Telegram Web или вкладки браузера).
5. Снова откройте окно расширения:
   - В окне появится готовый список всех уникальных токенов (каждый с новой строки).
   - Нажмите **«📋 Скопировать всё»** (для вставки в буфер).
   - Или нажмите **«💾 Скачать tokens.txt»** — готовый файл скачается в загрузки.
6. Нажмите **«⏹ Остановить запись»**.

---

## 🛡️ Безопасность

- Перехватывает запросы **исключительно** к доменам `*.tgmrkt.io`.
- Никуда не отправляет данные — токены хранятся только локально в защищённом хранилище вашего браузера (`chrome.storage.local`).
- Автоматически фильтрует дубликаты (один и тот же аккаунт добавится только один раз).
